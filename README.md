# FabricNet-XAI

## Evaluating the Reliability of Explainable Deep Learning for Woven Fabric Structure Classification

### Project Overview

This project investigates the reliability of Explainable Artificial Intelligence (XAI) methods in deep learning-based woven fabric structure classification.

A ResNet-18 transfer learning model will be developed to classify microscopic woven fabric images into three categories:

- Plain
- Twill
- Satin

The project focuses on evaluating whether the explanations generated by Grad-CAM and Integrated Gradients are stable and faithful to the model's predictions.

### Research Objectives

1. Develop a reproducible ResNet-18 transfer learning classification model.
2. Generate explanations using Grad-CAM and Integrated Gradients.
3. Evaluate explanation stability under small image perturbations.
4. Evaluate explanation faithfulness using occlusion-based testing.
5. Compare the reliability of the two XAI methods.

### Dataset

**FabricNET (Seckin et al., 2023)**

- Total images: 130
- Plain: 50
- Twill: 39
- Satin: 41
- Original image resolution: 640 × 480
